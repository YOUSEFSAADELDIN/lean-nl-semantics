lean-nl-semantics · FraCaS test suite

342 sentences of natural-language reasoning, checked by a machine that cannot be fooled.

The FraCaS test suite (Cooper et al., 1996) is a set of textbook inference problems in plain English — the kind a person answers by reading a sentence and thinking about what follows from it. Every one of them has been translated into a formal logical statement and proved, or refuted, inside the Lean 4 proof assistant: a system that checks each proof step by step and rejects anything that doesn't actually follow. This page is a guided look at all 342.

How one sentence becomes a verified proof

Problem 2 walks the full pipeline: an English sentence, a formal grammar tree that regenerates the same sentence mechanically, and a Lean theorem the kernel has checked. Every problem on this page followed some version of this path.

Problem 2 (FraCaS §1, Generalized Quantifiers) — "Every Italian man wants to be a great tenor." The grammar tree is written by hand once, then mechanically regenerated back into English (via GF's linearize) to confirm it says exactly this sentence and no other reading of it. The Lean theorem fracas_002_from_gf is not merely "similar" to the hand-formalized fracas_002 — its proof is a direct application of it, so it only typechecks because the two propositions are exactly the same shape.
